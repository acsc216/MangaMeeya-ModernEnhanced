# 原版二进制（未修改）

本目录保留 **MangaMeeya v7.4 中文版的原始二进制**，用于对照与回退：

| 文件 | 说明 |
|---|---|
| `MangaMeeya.exe` | 原版主程序（未开启 LAA） |
| `arc.dll` | 原版压缩包插件（未修复 ZIP64） |

## 校验值

完整摘要见仓库根目录的 `SHA256SUMS.txt`。原版文件摘要：

- `MangaMeeya.exe`: `fe23717389996cc7a4fb5e3df7595df0e1456264e9d8d02d1792ddf5608332ed`
- `arc.dll`: `b1d2f82f7a105d375fb7da40891fca4596cc58d40fb04cafedf0454a1c318cc2`

## 回退方法

把本目录的两个文件复制到上一级目录覆盖同名文件即可恢复原版行为。
其余 DLL 与插件在两个版本中相同，根目录已经包含。

恢复原版后，根目录的 `mmunicode.dll` 不再被加载，可以安全删除。使用原版 `MangaMeeya.exe` 时，特殊字符文件名（如含「・」的名称）将重新无法打开。
